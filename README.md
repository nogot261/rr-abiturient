# Информационная система «Абитуриент»

Учебный проект для рейтинговой работы по дисциплине «Проектная деятельность в ИТ».

**Обучающийся:** Федосеев Кирилл Валерьевич  
**Группа:** о.ИЗДтс 23.1/Б3-25  
**ID:** 70255366

## Назначение

Проект демонстрирует базовую структуру информационной системы для учета абитуриентов, направлений подготовки, заявлений и статусов поступления.

## Структура

- `app.py` - демонстрационный сценарий;
- `data.py` - модель данных;
- `tests/test_app.py` - автоматическая проверка;
- `docs/WBS.md` - иерархическая структура работ;
- `docs/requirements.md` - основные требования;
- `docs/data_model.md` - описание модели данных.

## Запуск

```bash
python app.py
```

## Проверка

```bash
python -m unittest discover -s tests -v
```

# Иерархическая структура работ

1. Анализ
   - определение пользователей;
   - формирование требований;
   - описание основных сущностей.
2. Проектирование
   - модель данных;
   - структура модулей;
   - права доступа.
3. Реализация
   - модель абитуриента;
   - демонстрационный сценарий;
   - фильтрация по конкурсному баллу.
4. Тестирование
   - проверка фильтрации;
   - проверка демонстрационных данных.
5. Выпуск
   - оформление README;
   - проверка структуры репозитория;
   - подготовка публичной версии.
